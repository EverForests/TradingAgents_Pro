# D5 public session evidence

The files below are redacted derivatives of the existing annotated course sessions, identified by GitHub collaborators rather than student numbers. They do not add new sessions. Student numbers, direct contact identifiers, local home paths and credential-like values are removed or masked. Full originals remain in the restricted course submission.

`redacted-exports/` contains corresponding de-identified source derivatives. The [manifest](source-export-manifest.json) records public-file hashes. Original source hashes and complete student identifiers belong to the private package. Redaction changes identifying strings, so public derivatives are not byte-identical raw exports and cannot replace the originals for source-authenticity review. Original message/session locations remain useful for consulting the private evidence.
